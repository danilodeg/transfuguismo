⚙ Configurar Apps Script para escritura en Sheets
1
En tu Google Sheet, abrí el menú Extensiones → Apps Script
2
Reemplazá todo el contenido del editor con este código y guardá (Ctrl+S): function doPost(e) { const ss = SpreadsheetApp.getActiveSpreadsheet(); const sh = ss.getSheets()[0]; const id = e.parameter.id; const tipo = e.parameter.tipo_cambio; const data = sh.getDataRange().getValues(); const headers = data[0]; const idCol = headers.indexOf('id'); const tipoCol = headers.indexOf('tipo_cambio'); if (idCol === -1 || tipoCol === -1) { return resp({status:'error', message:'Columnas no encontradas'}); } for (let i = 1; i < data.length; i++) { if (String(data[i][idCol]) === id) { sh.getRange(i + 1, tipoCol + 1).setValue(tipo); return resp({status:'ok', row: i + 1}); } } return resp({status:'error', message:'ID no encontrado: ' + id}); } function resp(obj) { return ContentService .createTextOutput(JSON.stringify(obj)) .setMimeType(ContentService.MimeType.JSON); }
3
Hacé clic en Implementar → Nueva implementación

Hacé clic en Implementar y autorizá cuando te lo pida.
